# HaiA 设计规范

HaiA 的界面遵循 macOS 深色外观：中性灰的层次、一个强调色、克制的控件。这份规范描述的就是代码里已经生效的规则——颜色和尺寸在 `src/ui/tokens.css`，控件外观在 `src/ui/components.css`，其中能自动检查的部分由 `test/design-tokens.test.cjs` 守住。

规范与代码不一致时，以这份文档为准去改代码；要改规范，同时改这三处。

## 1. 原则

1. **内容最暗，浮层最亮。** 读消息的地方最安静；越是临时出现的东西（弹窗、菜单）越亮。
2. **蓝色只留给“要你操作”的东西。** 主按钮、发送键、当前选中项、未读数。一个界面里只有一个蓝色主按钮。
3. **红、绿、橙只表达含义。** 红＝危险或不可撤销，绿＝正常或在线，橙＝受限或需要留意。不做装饰用。
4. **同一种控件只有一种样子。** 新界面复用已有控件，不在局部重新写一个按钮或输入框。
5. **粗体是稀缺的。** 只给标题和未读；列表里的名字用中等字重。

## 2. 颜色

### 表面（由暗到亮）

| 令牌 | 色值 | 用在哪 |
|---|---|---|
| `--rail-bg` | `#18181a` | 账号栏、标题条 |
| `--content` | `#1c1c1e` | 会话区、会话顶栏、输入区 |
| `--sidebar` | `#252527` | 会话列表、右侧资料栏 |
| `--raised` | `#2c2c2e` | 弹窗、卡片 |
| `--menu` | `#323234` | 菜单、选择器、提示、悬浮工具条 |

### 填充与分隔线

填充是半透明白，可以叠在任何表面上。

| 令牌 | 用在哪 |
|---|---|
| `--fill` (8%) | 默认按钮底、卡片行、悬停 |
| `--fill-hover` (12%) | 按钮悬停 |
| `--fill-strong` (18%) | 分段控件选中项、开关关闭态 |
| `--control` (5%) | 输入框、搜索框底色 |
| `--line` (8%) / `--line-strong` (16%) | 分隔线 / 控件与浮层描边 |

### 文字三档

| 令牌 | 色值 | 用在哪 | 对 `--content` 对比度 |
|---|---|---|---|
| `--ink` | `#f2f2f7` | 正文、标题 | 约 15:1 |
| `--muted` | `#a1a1a8` | 次要信息、标签、时间 | 约 6.6:1 |
| `--faint` | `#8a8a91` | 占位符 | 约 4.9:1 |

正文与次要文字的对比度不低于 4.5:1。

### 强调色与语义色

| 令牌 | 色值 | 含义 |
|---|---|---|
| `--accent` | `#0a84ff` | 主操作、选中、未读数 |
| `--accent-ink` | `#64b0ff` | 深色底上的蓝色文字（文字按钮、链接） |
| `--accent-soft` | 20% 蓝 | 选中卡片底、聚焦光环 |
| `--danger` / `--danger-ink` | `#ff453a` / `#ff7b72` | 删除、移除、挂断、错误提示 |
| `--ok` / `--ok-ink` | `#30d158` / `#63dc83` | 在线、已保存、接听 |
| `--warn` / `--warn-ink` / `--warn-bg` | `#ff9f0a` 系 | 受限、需要留意的提示 |
| `--bubble-out` / `--bubble-in` | `#0a6fdc` / `#2c2c2e` | 发出 / 收到的消息气泡 |

账号头像的六种色调（`.iris` `.teal` `.plum` `.clay` `.ocean` `.olive`）只用于区分账号和联系人，不用于控件。

**布局样式文件里不允许出现十六进制颜色**，黑白透明叠加（如 `#0000002e`）除外。

## 3. 字体

系统字体：`-apple-system`（SF Pro），中文回退到苹方 / 微软雅黑。界面基准 13px，行高 1.4。

| 字号 | 字重 | 用在哪 |
|---|---|---|
| 20 | 600 | 空状态标题 |
| 17 | 600 | 资料栏里的名字 |
| 15 | 600 | 会话标题、弹窗标题 |
| 14 | 400 | **消息正文**（内容比界面大一号） |
| 13 | 400 / 500 | 界面正文、按钮、输入框、列表名字（500） |
| 12 | 400 | 列表摘要、说明文字、小按钮 |
| 11 | 500 | 字段标签、分组标题、时间 |
| 10 | 500 / 600 | 标签、徽标数字 |

只使用上表的字号。未读会话的名字用 600；除此之外正文区不用粗体。

## 4. 形状与尺寸

| 圆角 | 用在哪 |
|---|---|
| 5px | 小按钮、菜单项、标签 |
| 6px (`--r-control`) | 按钮、输入框、图标按钮、导航项 |
| 8px (`--r-card`) | 卡片、列表行、菜单、大按钮 |
| 12px (`--r-panel`) | 弹窗、选择器面板 |
| 999px | 胶囊：徽标、开关、成员标签 |

消息气泡是例外：14px 圆角，靠头像一侧的顶角 5px。

| 高度 | 用在哪 |
|---|---|
| 24px (`--h-small`) | 行内与工具条里的小按钮、小图标按钮 |
| 28px (`--h-control`) | 默认：按钮、输入框、下拉框、搜索框、图标按钮、导航项 |
| 36px (`--h-large`) | 空状态上唯一的主操作 |

间距取 2 / 4 / 6 / 8 / 12 / 16 / 20。弹窗内边距 20px；按钮之间 8px。

## 5. 图标

- 线性图标，24 网格，线宽固定 1.5px（任何尺寸下粗细一致）。
- 三种尺寸：**14px** 用在密集行里，**16px** 是默认，**18px** 用在账号栏。
- 图标颜色跟随文字；默认是 `--muted`，悬停或选中变 `--ink`。
- 新图标加到 `src/ui/visuals.js` 的 `paths` 里，用 `<i data-icon="名字">` 引用。不用 emoji 或文字符号（如 ✕、▼）充当图标。

## 6. 控件

### 按钮

| 类型 | 外观 | 什么时候用 |
|---|---|---|
| 默认 | 灰色填充、白字 | 绝大多数操作：取消、保存、选择图片 |
| 主按钮 `.primary` | 蓝底白字 | 这个界面存在的目的。**每个界面最多一个** |
| 危险 `.danger` | 红底白字 | 确认弹窗里不可撤销的那个按钮 |
| 危险文字 `.danger-item` | 灰底红字 | 行内的删除、移除 |
| 文字按钮 `.plain` `.detail-action` | 无底、蓝字 | 夹在内容里的次要动作：添加、清除、加载更多 |
| 图标按钮 `.icon-button` | 28×28、无底 | 工具栏动作。必须有 `title` 和 `aria-label` |

弹窗底部的按钮靠右排列，取消在左，默认操作在最右。按钮文字用动词（“创建群聊”），不用“确定”。

### 输入

文本框、搜索框、下拉框是同一个形状：28px 高、6px 圆角、`--control` 底、`--line-strong` 描边。聚焦时描边变蓝并带 3px 的 `--accent-soft` 光环。占位符只作示例，字段含义写在上方的标签里（12px、`--muted`）。

### 关闭

带标题栏的弹窗统一在右上角放 `class="icon-button dialog-close"` 的关闭按钮。有“取消 / 确认”的表单弹窗不再放关闭按钮，用取消。

### 选择与切换

- **分段控件**（会话类型、扫码/关联码、导入/导出）：灰色槽里的一排选项，选中项是浅色凸起。用于 2–4 个互斥视图。
- **来源列表**（设置导航、群组导航、会话列表）：选中项整行蓝底白字。
- **开关**：32×18，开为蓝色。用于立即生效的设置。
- **复选框 / 单选**：用于需要再点“保存”或属于一组选择的情况。

### 菜单

`--menu` 底、8px 圆角、5px 内边距；菜单项 26px 高，悬停整行蓝底白字，危险项红字、悬停红底。

### 徽标与标签

- 数字徽标：16px 高胶囊。账号栏用红色（需要你注意的账号），会话列表用蓝色（未读数），归档数用灰色。
- 标签（群聊、受限）：10px 字、4px 级圆角、灰色填充；受限类用橙色。

## 7. 布局

三栏：账号栏（68px）→ 会话列表（220–300px）→ 会话区，右侧资料栏按需出现。三栏用底色区分，不靠粗分隔线。

- 账号栏只有账号头像有颜色；底部的工具按钮是无底图标。
- 会话列表选中行是整个窗口里除发送键外唯一的大面积蓝色。
- 会话区最暗；收到的消息是灰色气泡，发出的是蓝色气泡。
- 右侧资料栏只常驻“经常要做的事”：静音 / 置顶 / 归档、备注、标签、群状态。偶尔才查的资料（昵称、签名、商家信息、共同群组、定时消失、来源账号）收在“更多资料”里，展开状态会被记住；屏蔽联系人单独放在最底部。

## 8. 动效与无障碍

- 过渡 100–160ms，缓动 `--motion`；`prefers-reduced-motion` 下全部关闭。
- `prefers-contrast: more` 下分隔线和次要文字自动加强。
- 所有可点击元素都有可见的键盘焦点环（`--ring`）。
- 仅有图标的按钮必须有 `aria-label`。

## 9. 怎么加新界面

1. 结构和位置写在对应的布局文件里（它们在 `layout` 层）。
2. 需要按钮、输入框、菜单时，把新元素的选择器**加进 `components.css` 里对应控件的列表**，或直接用已有的类（`.primary`、`.icon-button`、`.plain`、`.danger`）。不要在布局文件里写控件的颜色、圆角、高度。
3. 组件层的规则不分优先级地压过布局层。所以一旦在 `components.css` 里给某个元素写了底色，它的悬停、选中态也必须写在 `components.css`，写在布局文件里不会生效。
4. 需要新颜色时先看令牌里有没有；确实没有就在 `tokens.css` 加一个有含义的名字，并更新本文档。
5. 运行 `npm test`，再用 `RELAY_UI_CAPTURE=<目录> npx electron test/desktop-smoke.cjs <临时目录> first` 截图看一遍。
